Нейронная сеть для преобразования текста в эмбеддинги. intent: уловить "смысл". Реализация hugging face.

Выбрал именно эту модель, потому что она удобна - принимате 512 токенов на вход, этого хватает чтобы охватить >95 % текстов всех постов. Нацелена искать смысловое сходство, например между «Как привлечь покупателей нового продукта?»,
«Пять способов продвижения нового продукта…»

# BM25

новые оценки

```python
neighbors_c = [p for p in top_n if p.label == c]

number_close_bm25[c] = len(neighbors_c)

sum_bm25[c] = sum(p.bm25_score for p in neighbors_c)

resid_sum_bm25[c] = sum(p.bm25_score * p.resid for p in neighbors_c) 
```

Оценки для классов:

\forall классов (below, typical, above) добавится по 3 оценки:

- number_close_bm25_classname
- norm_sum_bm25_classname
- resid_sum_bm25_classname

Пример, доказывающий почему полезно дифференциировать оценки по классам:

| История | resid соседей | Среднее |
|---|---|---|
| A | 0, 0, 0, 0, 0 | 0 |
| B | -1, -1, -1, +1.5, +1.5 | 0 |

Если сделать только среднее или нормированное среднее по всем resid ближайших соседей, получится одинаковое число, когда в первом случае все посты typical и человек бы сказал, что текущий пост тоже typical, а во втором бОльшая часть постов below, следовательно человек бы сказал below вместо typical (0).

Оценка между классами:

среднее квадратическое отклонение resid в выборке ближайших соседей.

# Форматирование

Расширим базовые признаки, которые форматирования текста.


| Блок | Признаки | Как считать | Зачем |
|---|---|---|---|
| Эмодзи | n_emoji, n_unique_emoji, emoji_at_start | Количество эмодзи, количество разных, начинается ли текст с эмодзи | Описать эмоциональность и оформление |
| Пунктуация | n_exclamations, n_questions, n_repeated_punct | Количество !, количество ?, число серий из двух и более знаков !? | Различать спокойную и выразительную подачу |
| Регистр | uppercase_ratio, n_uppercase_words | Доля заглавных среди букв с регистром; число полностью заглавных слов длиной от двух букв | Выделять акценты, объявления, рекламную подачу |
| Абзацы и списки | n_paragraphs, first_paragraph_length, max_paragraph_length, n_list_items | Абзацы разделяются пустыми строками; длины — в символах; пункты определяются по маркерам и нумерации | Описать структуру и способ подачи текста |
| Отклонение от истории | emoji_vs_history, uppercase_vs_history, paragraphs_vs_history | Текущее значение минус среднее по последним 20 строго предыдущим постам автора | Отличать привычный стиль автора от изменения стиля |
